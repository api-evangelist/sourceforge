<p>Earlier this year, GitHub announced that it would be <a href="https://github.blog/2023-01-20-sunsetting-subversion-support/">sunsetting Subversion support</a> on January 8th, 2024. Since then, SourceForge has seen high volume of projects that use Subversion migrate to SourceForge. To all the new projects, welcome!</p>
<p>With GitHub&#8217;s support for Subversion due to end on January 8th, 2024, we&#8217;ve been getting questions about the future of Subversion on SourceForge.</p>
<p>This blog post is to let everyone know that Subversion will remain an option on SourceForge. SourceForge will never end support for Subversion. So if your project uses Subversion and you want to keep using it, we encourage you to migrate your project to SourceForge.</p>
<p>It&#8217;s really easy to move your project from GitHub to SourceForge. Simply use our <a href="https://sourceforge.net/p/import_project/github/">GitHub Import Tool</a> &#8211; it just takes a minute, and it&#8217;ll migrate everything from your GitHub project to SourceForge.</p>
<p>We believe users should have a choice about which version control system they use. So SourceForge will continue to support Git, Subversion, and Mercurial.</p><p>The post <a href="https://sourceforge.net/blog/github-is-ending-subversion-svn-support-subversion-and-sourceforge/">GitHub is Ending Subversion (svn) Support: Subversion and SourceForge</a> appeared first on <a href="https://sourceforge.net/blog">SourceForge Community Blog</a>.</p>
