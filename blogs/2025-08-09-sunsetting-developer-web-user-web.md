<p>SourceForge will be sunsetting developer web hosting for user accounts (unrelated to project web hosting) in 60 days on October 10th, 2025.</p>



<p>If you are using developer web hosting on your SourceForge user account, please make arrangements before October 10th, 2025. Project web hosting for projects will continue as is.</p>



<p>Please refer to our <a href="https://sourceforge.net/p/forge/documentation/Developer%20Web%20Services/">documentation</a> if you need help accessing your files hosted on developer web hosting.</p>
