<p>The purpose of this blog post is to announce our scheduled maintenance window for project web hosting. We will be upgrading the database used by project websites on SourceForge.</p>



<p>We will be doing it in alphabetical order, starting with projects that begin with the letter &#8220;A&#8221;. Each letter group of projects will take about 3 hours. We do not expect any significant downtime for the static portion of the websites. The database will be undergoing upgrades, however, so new comments or forum posts hosted on a project website will be unavailable for approximately 3 hours.</p>



<p>No action on your part is required.</p>



<p>There will not be any impact or downtime regarding projects on SourceForge, project downloads, or code repositories.</p>



<p>This database upgrade will begin on October 23rd.</p>



<p>We will update this blog post with progress. You can also refer to the <a href="https://mastodon.cloud/@sourceforgestatus@fosstodon.org">SourceForge Status</a> Mastodon page.</p>



<p>Projects starting with the following letters are complete: <strong>A-Z</strong></p>
