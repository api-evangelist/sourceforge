<p><b><a href="https://sourceforge.net/projects/xigmanas/"><br /><img alt="" src="https://sourceforge.net/p/xigmanas/icon" /> XigmaNAS</a></b><br />The XigmaNAS® NAS operating system can be installed on virtually any x64 hardware platform to share computer data storage over a computer network. XigmaNAS is the simplest and fastest way to create a centralized and easily-accessible server for all kinds of data!  XigmaNAS supports sharing across Windows, Apple, and UNIX-like systems. It includes ZFS, Software RAID (0,1,5), disk encryption, S.M.A.R.T / email reports etc. with the following protocols/services: CIFS/SMB (samba), Samba AD, FTP, NFS v4, TFTP, AFP, RSYNC, Unison, iSCSI, UPnP, Bittorent, Syncthing,  MariaDB with phpMyAdmin, VirtualBox, Bridge, CARP (Common Address Redundancy Protocol) and HAST (Highly Available Storage).  This all can easy be managed by a configurable web interface.<br />[ <a href="https://sourceforge.net/projects/xigmanas/files/latest/download">Download XigmaNAS</a> ]</p>
<p><b><a href="https://sourceforge.net/projects/berryboot-updated-images/"><br /><img alt="" src="https://sourceforge.net/p/berryboot-updated-images/icon" /> Berryboot Updated OS Images</a></b><br />This is the #1 source to download custom OS images for #Berryboot.  Original OS images were downloaded from their respective official websites, I did not modify any file from original nor convert OS images, however, some images have been modified to fix Berryboot incompatibilities. Most of the OS images were converted by using this method: https://www.berryterminal.com/doku.php/berryboot/adding_custom_distributions. Some projects already have their own OS images for Berryboot, in those cases, I just compress them and serve as a mirror.  You must know that I&#8217;m not part of the Berryboot project, I&#8217;m just a web developer with a Raspberry Pi 3, Odroid C2 &#038; Rock Pi S. I cannot offer full support on these images. However, if you find any issue, please contact me, I&#8217;ll look into it.  You can request Custom OS images at: https://berryboot.alexgoldcheidt.com/request-support-contact-form/<br />[ <a href="https://sourceforge.net/projects/berryboot-updated-images/files/latest/download">Download Berryboot Updated OS Images</a> ]</p>
